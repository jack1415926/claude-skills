# Claude Code Skills

Personal skill collection for [Claude Code](https://claude.ai/code).

## Install on new machine

```bash
git clone https://github.com/jack1415926/claude-skills.git ~/.claude/skills-repo
bash ~/.claude/skills-repo/setup.sh
```
